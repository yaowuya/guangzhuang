# 全球化妆品行业资讯平台推荐与专属网站设计方案

> **历史调研资料，不是当前需求或实施计划。** 其中 AI 摘要、翻译、会员、推送、团队、正文采集等建议已被当前 MVP 明确排除；权威范围见 `fp-docs/changes/beauty-intelligence-mvp/`。
>
> 面向中国全球化公司化妆品研发经理的每日情报需求
> 覆盖：全球各市场新品发布、潮流趋势、技术突破、法规动态

---

## 一、现有优质资讯网站推荐

目前市面上已有多类专业平台，可满足基本的每日查看需求。建议按「全球视野 + 中国视角 + 研发深度」组合使用。

### 1. 全球 / 国际向（新品、趋势、技术）

| 平台                                 | 特点                                              | 适合场景       |
| ------------------------------------ | ------------------------------------------------- | -------------- |
| **Global Cosmetics News**            | 每周汇总全球财务、监管、扩张、新品与技术动态      | 行业全景速览   |
| **BeautyMatter**                     | 每周品牌与产品发布汇总，覆盖新兴品牌、成分创新    | 新品追踪       |
| **Business of Fashion (BoF) Beauty** | 深度分析 + 商业新闻，新品与战略洞察强             | 战略与商业判断 |
| **WWD Beauty**                       | 权威商业与新品报道                                | 欧美市场动态   |
| **CosmeticOBS**（法国）              | 成分、法规、市场与趋势观察，欧洲视角扎实          | 成分与法规研究 |
| **HAPPI / Cosmetics Design 系列**    | 原料、配方、展会创新、技术突破覆盖较好            | 技术与原料跟踪 |
| **WGSN Beauty**（付费）              | 专业趋势预测（2–5年），成分、包装、美学、消费行为 | 中长期战略规划 |
| **PR Newswire**                      | 实时新品与公司公告源头                            | 一手新闻稿     |

### 2. 中国 / 亚太向（法规、国货、出海、原料备案）

| 平台                               | 特点                                                         | 适合场景         |
| ---------------------------------- | ------------------------------------------------------------ | ---------------- |
| **绿翊合规 BeautyNews**            | 每日更新中国化妆品行业资讯，覆盖监管窗口、新原料备案、出海、A股美妆 | 中国市场每日必看 |
| **聚美丽、青眼、化妆品报**         | 新品、趋势、科技进展、展会报道密集                           | 国货与行业深度   |
| 国家药监局 / 中检院公开信息        | 官方新原料、功效评价、法规原文                               | 合规与备案       |
| 行业年会 / 美博会 / CiE 等展会报道 | 最新技术与新品集中展示                                       | 技术趋势捕捉     |

### 3. 现有平台的主要痛点

- 信息分散，需多平台切换
- 语言切换成本高（中英混用）
- 研发经理真正需要的「技术突破 + 多市场新品对比 + 可落地洞察」常被商业新闻淹没
- 缺乏统一的中英双语、按研发维度（成分 / 剂型 / 功效 / 递送技术 / 法规影响）过滤的每日仪表盘

## 二、专属网站设计方案

如果现有平台仍无法高效满足需求，可考虑打造一个面向研发经理的专属情报平台。

### 1. 基本信息

- **网站名称建议**：CosmoRadar / 妆研雷达 / BeautyTech Pulse（中英双语）
- **核心定位**：研发视角的全球化妆品情报中心
  —— 新品发布、潮流趋势、技术突破一站式，强调**可行动洞察**而非纯新闻
- **目标用户**：中国全球化公司化妆品研发经理（每天投入 15–30 分钟快速掌握全球 + 中国关键动态）

### 2. 首页结构（每日更新仪表盘）

1. **今日速览（Daily Brief）**
   - 3–5 条最重要新闻（全球 + 中国）
   - 附「研发影响」标签（高 / 中 / 低）

2. **全球新品雷达（New Launches）**
   - 按市场筛选：中国、美国、欧洲、日韩、东南亚、中东等
   - 按品类：护肤、彩妆、洗护、香氛、功效型
   - 卡片展示：品牌、核心成分/技术、宣称功效、上市时间、渠道、简要配方亮点
   - 支持对比功能（同功效不同技术路径）

3. **技术突破与原料创新（Tech & Ingredients）**
   - 新原料备案（中国 NMPA）
   - 临床数据、递送系统（微针、外泌体、超分子、PDRN、线粒体/长寿科学等）
   - AI 配方工具、可持续工艺
   - 标注来源（IFSCC、专利、原料商发布、学术论文）

4. **潮流趋势看板（Trends）**
   - 短期（本季）：病毒成分、包装美学、剂型创新
   - 中长期（WGSN 风格）：长寿护肤、神经美容、精准护肤、可食用美容等
   - 可视化：热度曲线、区域差异地图

5. **法规与合规速递**
   - 中国新原料/功效评价更新
   - 欧盟 CLH、美国防晒、东南亚清真等
   - 标注对研发的直接影响

6. **深度专题与周报**
   - 每周《研发周报》PDF / 邮件：本周 Top 10 新品技术拆解 + 趋势信号
   - 月度技术白皮书（如「PDRN 从医美到日化的路径」）

### 3. 关键功能（提升研发效率）

- 智能筛选 + 关键词订阅（成分、技术关键词、竞品品牌）
- AI 摘要 + 研发影响评分（「此技术对屏障修复配方的可借鉴度」）
- 中英双语，一键切换
- 支持微信 / 邮件 / 企业微信推送
- 数据库：历史新品库、成分热度排行、专利追踪
- 会员分层：免费每日速览 + 付费深度技术拆解与竞品对标报告
- 移动端优先 + 企业账号（团队共享笔记、标记「已跟进」）

### 4. 内容来源与更新机制

- 自动抓取 + 人工编辑（PR 稿、监管网站、展会、学术、原料商、主流媒体）
- 与行业协会、原料供应商、检测机构合作获取一手信息
- 每日早间更新（北京时间），晚间补充欧美动态

### 5. 商业模式建议（可持续运营）

- Freemium：基础资讯免费，深度报告 / 数据库 / 定制情报付费
- 企业订阅（年费）+ 赞助原料商 / 展会内容合作
- 数据服务：匿名化趋势报告出售给品牌方

### 6. 技术实现简要

- 前端：现代化仪表盘（类似 Bloomberg 终端简化版），支持筛选与卡片流
- 后端：爬虫 + NLP 分类（新品 / 技术 / 法规）+ 人工审核
- AI 辅助：自动摘要、影响评分、多语言翻译

---

## 三、总结与下一步建议

现有网站已能基本满足「每天查看」的需求，但信息分散、研发视角不够聚焦是主要痛点。

**推荐行动路径**：
1. 先组合使用现有平台（绿翊合规 + Global Cosmetics News / BeautyMatter + BoF Beauty + WGSN）。
2. 如果仍感觉效率不足，可按上述方案设计专属平台，重点解决「多市场对比 + 技术可落地性 + 中英统一仪表盘」问题。

如需进一步细化（例如：每日必看清单与订阅方式、某个模块的详细原型、竞品对标模板等），可继续提出具体需求。
