# 全球化妆品资讯平台与研发情报网站设计方案

> **历史调研与早期设计资料，不是当前需求或实施计划。** 其中摘要、事件归并、来源管理、导出等早期方向已被标题版 MVP 收敛；权威范围见 `fp-docs/changes/beauty-intelligence-mvp/`。
>
> 适用对象：中国化妆品企业的研发经理、产品开发负责人及创新团队
> 资料核查日期：2026年10月26日
> 文档内容：现有平台推荐、使用组合、内部情报网站设计及第一版功能范围
> 网站部分为设计方案，尚未实施实时资讯接入。

## 一、核心判断

市面上已经有比较成熟的化妆品专业资讯平台。对研发经理而言，建议分成三类使用：**行业资讯网站、全球新品数据库、原料与研发技术平台**。三类平台解决的问题不同，组合使用更贴近日常工作。

- **综合资讯入口：**优先看 Premium Beauty News。
- **研发技术动态：**优先看 Cosmetics & Toiletries，简称 C&T。
- **全球新品与竞品数据库：**有企业采购预算时，优先评估 Mintel GNPD。
- **原料与配方落地：**结合 SpecialChem Cosmetics 使用。
- **未来产品线与中长期趋势：**评估 WGSN Beauty。

上述优先级是根据研发经理的工作任务提出的选型建议，不代表必须全部订阅。

## 二、现有资讯网站与专业平台

### 2.1 全球动态、研发技术与原料平台

| 网站 | 主要内容 | 对研发工作的实际用途 | 阅读方式与使用边界 |
|---|---|---|---|
| **[Premium Beauty News](https://www.premiumbeautynews.com/)** | 全球新品、市场趋势、科学研发、原料配方、包装设计 | **适合作为综合入口。** 同时发现品牌新品、供应商创新和研发方向；官网按欧洲、北美、拉美、亚太等地区分类 | 英文、法文；有公开新闻和免费周报。[1] |
| **[Cosmetics & Toiletries，简称 C&T](https://www.cosmeticsandtoiletries.com/)** | 新原料、配方技术、研究、测试、专利线索 | **贴近研发经理的日常工作。** 追踪新技术、配方方法及评价思路 | 英文；有免费每日邮件，深度技术内容需要注册账号。[2][3] |
| **[SpecialChem Cosmetics](https://www.specialchem.com/cosmetics)** | 原料目录、INCI、供应商、技术资料、起始配方 | 发现成分或技术方向后，继续查原料、供应商和配方参考，帮助判断开发路径 | 英文为主；属于原料与配方平台，其“新品”主要指原料。[4][5] |
| **[Cosmetics Business](https://cosmeticsbusiness.com/)** | 全球品牌动态、新品、趋势、包装、原料及零售 | 跟踪国际品牌动作、产品线变化和商业化趋势 | 英文；部分内容需要订阅，提供个人和团队方案。[6] |
| **[BeautyMatter](https://beautymatter.com/)** | 美妆商业观察、品牌案例、趋势分析及研究报告 | 理解新概念出现的原因、品牌定位，以及消费变化带来的产品机会 | 英文；深度内容采用会员订阅。[7][8] |

**旧推荐更新：CosmeticsDesign。** 其官方账号已经宣布关闭原有网站，美妆报道转到 NutraIngredients。因此，不宜继续把 CosmeticsDesign 美国、欧洲和亚洲站列为持续更新的日常入口。[9]

### 2.2 中国、日本、韩国的本地资讯源

本地来源各有作用：行业媒体提供分析，品牌新闻稿提供上市信息，新品日历便于按时间找产品。

| 市场 | 网站 | 建议重点关注的内容 |
|---|---|---|
| **中国** | **[聚美丽](https://wx.jumeili.cn/)** | 有“全球新品速递”“成分特辑”“皮肤科学”“研发”等栏目，适合关注中国品牌的成分创新和科研表达；部分文章全文需要手机号验证。[10] |
| **中国** | **[青眼](https://www.iqingyan.cn/)** | 中国美妆行业动态、市场洞察、消费者研究、品牌及工厂访谈。媒体资讯与“青眼情报”的研究服务应分开看。[11] |
| **中国** | **[品观／化妆品观察](https://www.pinguan.com/media)** | 品牌、趋势、供应链、渠道及产业合作，补充国内竞品和商业化信息。[12] |
| **日本** | **[PR TIMES Beauty](https://prtimes.jp/beauty/)** | 日本企业发布的新品、品牌活动及研究新闻稿，适合追踪官方发布信息；应区分企业宣称与独立研究结论。[13] |
| **日本** | **[@cosme 新品日历](https://www.cosme.net/calendar/)** | 按日期查日本市场新品，适合安排竞品跟踪和买样；日历按上市日展示品牌及产品。[14] |
| **韩国** | **[COSIN Korea](https://cosinkorea.com/)** | 韩国美妆行业动态，以及新材料、新原料、技术信息、专利和论文资料；研发相关栏目比较完整，专业期刊另有订阅入口。[15] |

### 2.3 有采购预算时，重点评估的数据库与预测平台

| 平台 | 核心价值 | 优先考虑的工作场景 |
|---|---|---|
| **[Mintel GNPD：英敏特全球新品数据库](https://www.mintel.com/products/gnpd/)** | 系统追踪多市场新品，提供宣称、包装、成分、香型、质地、剂型等数据与分析；官网美妆介绍列出覆盖86个市场 | 经常需要做竞品清单、新品扫描、成分趋势和立项研究时。具体数据库权限和报价需要向官方确认。[16][17] |
| **[WGSN Beauty](https://www.wgsn.com/en/products/beauty)** | 消费者变化、未来产品、成分、色彩、包装及设计方向；主要预测跨度为2—5年，也有短期趋势和展会观察 | 制定未来产品线和中长期创新方向时。它与每日新闻、新品逐款检索的用途不同。[18] |

### 2.4 推荐使用组合

| 工作任务 | 推荐组合 |
|---|---|
| 每天浏览行业与研发动态 | Premium Beauty News＋C&T＋聚美丽 |
| 追踪日韩新品 | PR TIMES／@cosme＋COSIN |
| 项目立项时深入查竞品与原料 | Mintel GNPD＋SpecialChem |
| 规划未来产品方向 | 根据预算评估 WGSN Beauty |

采购数据库前，建议让供应商使用真实课题演示。例如，以“近三个月日韩新上市面膜”为题，检查品牌覆盖、产品图片、上市日期和成分字段是否满足团队需要。

## 三、是否需要建设内部网站

现有平台已经能提供大量内容。自建网站的主要价值，是把这些信息整理成适合研发团队使用的统一入口。

建议的使用目标是：

> 每天只打开一个中文页面，就能看到全球新品、潮流趋势和研发技术，并迅速判断哪些值得研究。

建议网站名称：**全球美妆研发情报台**。

核心工作包括：

1. 跨语言汇总信息。
2. 合并同一事件的重复报道。
3. 提取产品与技术字段。
4. 按团队关注的市场、品类和技术方向排序。
5. 将值得跟进的信息收藏并导出，用于产品评审和研发例会。

## 四、网站页面设计

### 4.1 整体只设两个页面

采用简洁、留白的视觉风格，以白底、深色文字和少量强调色为主。右上角放置卡通头像，不显示姓名文字。

| 页面 | 主要任务 | 设计重点 |
|---|---|---|
| **资讯首页** | 每天看信息、筛选、搜索、收藏、查看详情 | 所有内容集中在一个页面，以图片和简短文字构成瀑布流 |
| **来源管理页** | 添加、编辑、启停信息源，查看更新状态 | 管理来源名称、网址、地区、语言、内容类型和更新频率 |

### 4.2 首页从上到下的布局

| 页面区域 | 展示内容 | 交互方式 |
|---|---|---|
| **顶部导航** | 网站名称、搜索框、来源管理入口、头像 | 搜索品牌、产品、成分或技术关键词 |
| **今日重点** | 精选3—5条值得关注的信息，每条只写一句重点 | 点击进入对应详情，快速完成第一轮浏览 |
| **内容分类** | 全部、新品发布、趋势洞察、新原料、研发技术、包装剂型、OEM／ODM | 切换分类，不跳转页面 |
| **筛选区** | 地区、品类、时间、关注关键词 | 可组合筛选，例如“韩国＋面膜＋近30天” |
| **瀑布流资讯区** | 产品图或技术图、标题、核心亮点、日期及来源 | 有图展示图片；没有图片的内容直接使用文字卡片 |
| **详情侧栏** | 中文摘要、原文信息、技术或产品细节、相关报道 | 点击卡片从右侧展开，保留当前阅读位置 |

首页的主要空间应留给信息卡片。大面积统计数字和复杂图表可以后置，先让用户快速发现值得看的产品和技术。

### 4.3 三类资讯卡片

| 卡片类型 | 卡片优先展示 | 点击后查看 |
|---|---|---|
| **新品卡片：出了什么？** | 真实产品图片、品牌／品名、上市市场、特色成分、剂型或结构亮点 | 上市日期、规格、原文宣称、成分信息、包装细节、来源链接 |
| **趋势卡片：什么正在变化？** | 趋势名称、发生地区、代表性产品或品牌、简短变化说明 | 观察时间范围、支持案例、不同市场的表现、对产品开发的启发 |
| **技术卡片：有什么值得研究？** | 技术／原料名称、研发机构或供应商、解决的问题、研究或应用阶段 | 原始论文／专利／技术资料、实验条件、应用限制、潜在配方方向 |

可先将以下方向设置为优先关注关键词：**面膜膜布、双剂叠敷、冻干、发酵、屏障修护、抗衰、面霜质地**。关键词随项目调整，无需改变网站结构。

## 五、网站应重点做好的五件事

### 5.1 分清新闻日期与上市日期

每条新品至少保留以下日期字段：

| 字段 | 含义 | 记录原则 |
|---|---|---|
| 报道发布日期 | 文章什么时候发布 | 以原文标注为准 |
| 该市场上市日期 | 产品什么时候在当前市场上市 | 必须与具体市场关联 |
| 首次上市日期 | 产品最早什么时候上市 | 有可靠来源时记录 |
| 收录时间 | 系统什么时候发现这条信息 | 用于追踪采集与更新 |

同时标明产品属于**正式新品、上市预告、改版升级、渠道上新，还是旧品参考**。

例如，某产品去年已在韩国上市，今年才进入中国电商，应标为“中国渠道上新”。查不到首次上市时间时，显示“未披露”，不要用报道日期代替。

### 5.2 同一件事只占一张主要卡片

同一新品可能同时出现在品牌官网、PR TIMES和多家行业媒体。

首页将其合并为一条，详情中保留不同来源，让用户看到真正新增的信息，减少多篇转载反复占用注意力。

### 5.3 技术消息显示研究或应用阶段

技术卡片直接注明来源和阶段，例如：

- 供应商技术资料。
- 论文研究。
- 专利公开。
- 原型展示。
- 成品应用。

有条件时，再记录体外实验、人体测试等证据类型，帮助研发团队判断下一步应联系供应商、查阅论文，还是安排买样。

### 5.4 中文摘要与原文保持对应

首页采用中文标题与简短摘要，详情保留原始品牌名、原料商品名、INCI和原文链接。

“值得参考的开发方向”可由系统辅助整理，但应单独标为分析意见，避免与原文事实混在一起。

### 5.5 明确各来源更新到了什么时候

来源管理页展示最近一次成功更新、更新频率和异常状态。

信息接入优先使用可用的RSS、官方接口、订阅邮件及允许采集的页面；付费数据库按企业授权范围接入。来源暂时未更新时，保留准确的最后更新时间。

## 六、第一版功能范围

第一版建议收敛为六项功能：

| 功能 | 第一版应实现的内容 |
|---|---|
| **来源管理** | 先接入一批与研发工作直接相关的来源，支持添加、编辑、启停及查看更新状态 |
| **中文资讯汇总** | 将多语言内容整理为中文标题和摘要，保留原文入口及准确日期 |
| **去重与分类** | 合并同一事件，按新品、趋势、原料和技术分类 |
| **瀑布流展示** | 有图展示，无图使用紧凑文字卡片 |
| **组合筛选与搜索** | 按地区、品类、时间和关键词检索信息 |
| **收藏与导出** | 将选中信息整理为产品评审或研发例会材料 |

## 七、建议采用的建设方向

优先采用：**现成专业平台提供内容＋内部单页情报台集中阅读**。

现有平台可以立即开始使用。自建部分聚焦于减少重复阅读、保证新品日期准确，以及让资讯更容易转化成研发选题。

这份方案的重点是建立稳定的阅读与筛选入口。实际接入范围、更新频率及付费内容展示权限，应在实施时逐一确认。
