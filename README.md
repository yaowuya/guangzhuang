# guangzhuang

> 每天早上，看见全球化妆品的前沿。

## 项目目的

本项目面向**中国化妆品产品开发从业人员**，目标只有一件事：

**每天早上，用一份内容，看到全球化妆品的前沿信息。**

具体希望覆盖三类信息：

| 方向 | 关注内容 |
| --- | --- |
| **流行趋势** | 全球及区域市场的趋势走向，如成分趋势、功效诉求、品类变化、审美与包装风向等 |
| **市场热门产品** | 各热门地区市场（如北美、欧洲、日韩、东南亚等）当前的热销产品与高讨论度产品 |
| **前沿技术突破** | 配方、原料、递送体系、功效评价与检测等方向的科研进展和技术突破 |

## 为什么需要它

化妆品产品开发依赖持续的外部输入：哪些成分和技术正在突破、哪些趋势正在起势、哪些产品在成熟市场和新兴市场卖得好。

这些信息天然分散——不同国家、不同语言、不同渠道，人工逐日搜集成本高，也容易遗漏。本项目就是为把这个过程自动化、日常化而存在。

## 信息来源

**信源是全球的，不限于中文。**

只要信息有价值，无论来自哪个国家、哪种语言，都应被纳入。典型来源包括：

- **英文**：欧美市场媒体、行业媒体、原料商与检测机构动态、学术期刊与专利
- **日文 / 韩文**：日韩市场动向、本土热销榜单、当地研发与原料进展
- **中文**：国内趋势、本土原料与供应链动态
- **其他语言**：东南亚、欧洲其他语种等区域市场信息，按需覆盖

## 呈现方式：统一转成中文概览

原始信源语言各异，但**页面查看时统一转成中文概览**——使用者不需要懂多国语言，也能在一个页面里读完全球信息。

- **中文概览为主**：每条信息以中文摘要呈现，说清「是什么、为什么值得关注」
- **保留关键原文**：产品名、品牌名、成分名（INCI）、机构名、人名等保留原文，便于检索与溯源，避免翻译造成歧义
- **保留来源链接**：每条信息附原始出处，需要深挖时可回到原文

## 目标形态

- **频率**：每日一次，早晨送达
- **形式**：结构化摘要，便于快速扫读，可按方向、地区筛选
- **可溯源**：每条信息附带来源链接

## 当前状态

项目刚刚起步，仓库目前仅包含本说明文档，用于明确目标与范围。后续将围绕信息采集、整理与每日分发逐步展开。

## 说明

本项目聚焦**信息获取与整理**，服务于产品开发决策参考；不构成对任何成分、产品或功效的宣称与推荐。
