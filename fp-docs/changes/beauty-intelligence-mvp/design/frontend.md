### 架构主线

用户打开同域 HTTPS 站点；未登录时进入登录页。通过服务器认证后，进入标题工作台，按 URL 中的筛选条件请求分页列表。点击标题打开出处侧栏，进入原文或收藏；返回时保留筛选和原列表位置。手动刷新、重试只提交任务并显示后端结果，不在浏览器执行抓取。

前端采用 `app/features/shared` 特性目录：`app` 只负责 Vue 组合根、路由和跨 feature 装配，`features` 按 auth/headlines/bookmarks/sources/update-jobs 组织，`shared` 保存不依赖 feature 的 HTTP 契约和基础设施。shared 不依赖 features/app，features 不依赖 app；架构测试持续守卫该方向。旧交互稿仅提供视觉与交互参考，不能把其浏览器存储或虚构内容当作生产能力。

#### API 模块

新建轻量同源请求封装，调用 [后端接口表](<backend.md#接口权限与兼容边界>)。读取 `session` 确认会话；写请求携带会话绑定的 CSRF 标记。所有请求区分加载、成功、空结果、未认证和失败，不在控制台输出凭据或未经允许的原文。

列表与详情只消费后端返回的字段。原文、图片 URL 必须是后端核验过的可接受地址；前端不能把未知地址写入任意 HTML，也不解析来源 HTML。文本使用 Vue 默认转义，不使用原站 HTML 直接渲染。

#### 路由

使用 Vue Router 管理 `/login`、`/` 与 `/favorites`。未认证时路由守卫导向登录页，但服务器对每个业务接口独立鉴权；路由守卫不是安全边界。登录后的返回地址仅允许站内已知路径，避免跳转至外部地址。

详情和来源面板是当前页面状态，不要求独立路由或额外业务页面；浏览器返回与关闭面板不破坏筛选。静态页面与 API 均从 D-018 同一 HTTPS 域名提供。

#### 状态管理

- 使用页面局部状态维护列表、分页、面板与选中条目；使用共享逻辑维护当前会话、请求状态和收藏操作，不引入全局状态框架。
- 搜索、分类、地区、品类、日期和页码使用 URL 查询参数；参数只接受接口支持的合法值，变更筛选时回到第一页。未知值仍由后端判定，不在前端猜测。
- 列表详情来回时保存并恢复滚动位置；筛选生效后重置到结果起点。返回时不重新制造另一份列表或清空条件。
- 收藏以服务端确认后的状态为准；请求失败保持上次成功状态并提示，重复点击不能生成重复收藏。列表、详情和收藏视图共享同一条目的服务端结果。
- 更新提交返回任务标识后仅在页面需要时查询进度；组件卸载或任务结束停止查询。重复点击显示当前任务，不产生前端自行排队。
- 会话过期时提示并前往登录，保留安全的站内查询上下文；不在重新登录后自动重复提交收藏、刷新或重试写操作。

### 风险、迁移、发布、回滚与监控

| 具体失败场景 | 影响 | 预防或处理 | 发布/回滚/监控安排 | 证据 |
| --- | --- | --- | --- | --- |
| 原型业务内容与标题版范围冲突 | 旧摘要或模拟新闻被误当真实数据 | 只复用视觉与交互，不复制旧样本；标题版页面按当前 PRD 实现 | 发布前用真实来源和测试夹具检查 | D-001、D-008、D-025 |
| 图片外链不可用或来源不允许 | 卡片无图，可能影响浏览 | 有许可才展示；失败显示不可用，不影响标题、原文及收藏，不代理图片 | 本机和云环境分别验证网络；无法授权时无图 | [后端风险](<backend.md#风险迁移发布回滚与监控>)；D-026 |
| 服务器会话过期或写入失败 | 用户误以为收藏／刷新成功 | 明确显示过期或失败，保留最后已确认状态，不自动重放写请求 | 验证登录往返和错误状态；不记录密码 | D-017、D-026 |
| 来源迟到、未授权或零条 | 用户误认覆盖完整 | 明确标示未启用、失败、无新增或空库；不宣称全球全面覆盖 | 发布验收要求至少一个真实来源可用 | D-014、D-028 |
| 客户端组件／布局或页面回滚 | 视觉与接口版本不匹配 | 前后端共同按已确认接口发布；预览与版本回滚后再冒烟 | Caddy、前后端产物按同一版本恢复；数据回滚由后端章节控制 | D-018、D-024 |

有意延后：不引入大型组件库或全局状态框架；适用单人、少页面范围。若跨页面状态复杂度或组件复用在实际实现中增加，先以重复代码及维护成本为证据，再评估引入；当前不削减键盘、响应式与错误状态验收。
