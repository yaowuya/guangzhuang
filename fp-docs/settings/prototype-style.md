# FeaturePilot Prototype Style

## Usage

- 用于标题版美妆情报工作台的原型和后续生产视觉对照；当前权威视觉来源是获批 change-local legacy `prototype.html` 及其桌面/平板/手机静态图。
- 原型及专属证据为 local-only，不进入 Git；settings 只保存已确认的可复用视觉/交互约束。
- 不把原型虚构资讯、摘要、事件归并、成分、研究阶段、上市信息或模拟更新逻辑带入生产。

## Visual Direction

- Direction: Editorial greeting / light workspace；个人每日阅读优先于仪表盘监控感。
- 避免营销 Hero、KPI 卡、统计图、渐变、玻璃、彩色图标盒和阻塞内容出现的入场动画。
- 使用极浅灰绿色结构表面、白色内容面、深色正文和少量深青色关键操作/状态。

## Layout

- 最大内容宽度 1100px；12列网格，列间距 16px。
- 桌面内容导航约 224px；首行允许 8+4，后续 4+4+4；两条结果 6+6，单条占 12 列。
- 平板和手机将导航折为顶栏/可关闭面板；手机列表单列，筛选收进面板，搜索进入正常文档流。
- 详情桌面右侧 drawer（最大约590px），手机为全宽单区域；关闭后恢复焦点和滚动位置。

## Tokens

- 主内容面：`#ffffff`
- 结构表面：`#f4f6f5`
- 正文：`#1f201d`
- 强调：`#1b6e66`
- 基础间距：16px；标题卡圆角约22px；桌面控件高度约36–38px，手机触控目标至少44px。
- 字体：Instrument Sans 用于拉丁文字/数字，中文使用系统中文无衬线；外部字体/资源必须本地或有明确许可。

## Components and Content

- 工作台外壳：Navigation + Main；顶部全局标题搜索，导航承载全部、七类和收藏。
- 标题卡只显示来源原语言标题及允许元信息；无图时自然收缩，不放假图或摘要占位。
- 详情只显示标题、来源、明示日期、分类/地区/品类、允许图片、原文入口和收藏。
- 来源状态只读，入口许可与运行错误分开；无来源编辑/审核控件。
- 图片只使用后端允许的 HTTPS 外链；失败显示“图片暂不可用”，文字、原文和收藏保持可用。

## Interaction and Copy

- 筛选条件进入 URL；变更筛选回第一页；返回列表保留条件、滚动和焦点。
- 收藏、刷新和重试只在服务器确认后更新可见状态；失败保留上次成功状态，不自动重放写请求。
- 外部原文只在用户主动点击时新标签打开，并使用安全链接属性。
- 所有加载、空结果、无新增、读写失败、会话过期、来源待核验/受限状态须有明确且不混淆的文案。

## Verification

- 固定视口：1440×900、768×1024、390×844，并补测360px手机。
- 检查无横向溢出、键盘完整操作、可见焦点、隐藏导航不获焦、drawer焦点恢复、图片失败降级和各错误状态。
- 原型自身截图不能证明生产页面匹配；生产 runtime 必须独立记录构建身份、浏览器环境和视觉/E2E证据。

## Unknowns

- 最终登录页、真实标题长度、无图卡片和只读来源面板仍需在生产 runtime 完成独立视觉复核。
- 已初始化 `fp-docs/prototype-bases/frontend/manifest.json`（`static-modular`、`no-build`、mock-only、local-only）；后续刷新仍须运行 `/fp-prototype-init` 并遵守独立审批与 Git 忽略门禁。
